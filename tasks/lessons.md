# Lessons

## 2026-04-29 · External language and commit messages

- Scenario: project-facing documentation and git history for Sextant.
- Mistake: used a Chinese git commit message even though the project's external language is English.
- Next time: write public-facing project content and git commit messages in English unless explicitly asked otherwise.

## 2026-05-27 · Review output must include design update plan

- Scenario: reviewing Sextant implementation against the v0.2.0 design.
- Mistake: reported findings without consistently providing the corresponding design/update plan.
- Next time: every code review response must include both findings and a concise design update plan for how to fix or align the implementation.
